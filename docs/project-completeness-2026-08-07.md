## 五、主要缺口分级

### P0 — 外部依赖硬阻塞（不解决无法商用）
1. **认证**：仅 HS256 共享密钥手写验签，无登录/签发/刷新，无 OIDC/IdP 接入代码
2. **支付**：无任何支付渠道，充值 = admin 接口直接写账本
3. **真实 Provider**：Kling 3.0 / 阿里 Wan 2.7 / 火山 Ark 三个官方适配器已写完但 `production_ready=False`，无真实渠道 staging 验收
4. **生产 OBS**：凭据缺失，live 门禁阻塞
5. **备份/恢复、灰度/回滚、容量压测**：需求追溯中仅有的 3 项"未完成"

### P1 — 功能缺口（内部可做）
1. **TOC 个人空间**：AGENTS.md 已决策但代码库零实现
2. **发布中心**：仅内置 Mock provider，真实抖音/快手 OAuth 依赖外部插件注入，仓库内无适配器
3. **设置页**：仅 2 个本地 checkbox，无持久化
4. **社区首页**：纯静态数据，无后端接入
5. **逆向账号池**：框架就绪（槽位/RPM/冷却/粘性路由已测），真实渠道为零

### P2 — 工程卫生
1. `platform_api/main.py` 单体 3726 行、95 条路由无分层
2. 仓库残留 30+ 个 `test-temp-*` 临时目录与多个 `.db` 文件
3. `auth.py` 无单元测试；bootstrap 流程边界未测
