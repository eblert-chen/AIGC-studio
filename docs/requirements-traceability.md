## 口径

- **完成**：代码、自动化测试和当前可验证链路均已覆盖。
- **部分完成**：核心骨架或接口已存在，但还缺真实外部接入、完整界面或生产验收。
- **未完成**：需求对应的可用功能尚不存在。
- **外部阻塞**：代码已预留边界，但必须由真实供应商、身份平台、支付平台、云账号或运维环境提供资料与凭据后才能验收。

完成度不能只看代码行数。当前应分别看“工程骨架”“可用业务功能”和“公网商用验收”，其中任一 P0 未关闭都不能对真实客户收费。

## 上线结论

### 可放行

- 本机或白名单内网的研发联调；
- 明确标注 Mock 的演示；
- 测试公司、测试余额和非敏感素材；
- 每次演示前重新执行自动化测试、迁移、容器健康检查和整链路冒烟。

### 不可放行

- 公网真实客户注册或登录；
- 连接真实支付并充值；
- 对真实客户计费；
- 宣称已经接入真实生成渠道；
- 宣称产物已经通过生产华为云 OBS 验收；
- 在没有真实外部监控告警、死信运营看板和备份恢复的情况下承诺商用 SLA。

## 关闭公网商用门禁所需输入

1. 目标 IdP/SSO 的 issuer、Authorization/Token/JWKS 端点、public client ID、精确 redirect URI、账号管理 URL、owner 固定 subject 及 WebAuthn/passkey 策略；项目内登录和账号生命周期代码不再依赖外部 Auth Broker。
2. 至少一个真实 Provider 的测试账号、额度、地区/模型权限、账单与异常提交对账；三家官方文档与接口文件已具备。
3. 公司提供的逆向 API 文件及账号池字段、限流/冷却/失效规则。
4. 私有华为云 OBS 桶、最小权限 IAM、域名/CORS/生命周期和测试凭据。
5. 支付渠道、订单状态机、签名回调、退款和对账规则。
6. 生产域名、TLS、网络拓扑、密钥系统、日志/指标/告警平台和接收人。
7. 数据库/OBS 备份策略、恢复目标（RPO/RTO）和回滚窗口。
