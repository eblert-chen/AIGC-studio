# 第一里程碑：双平台可运行骨架

## 目标

在不假装已经接入真实渠道的前提下，完成一条可测试的业务闭环：

```text
公司和成员
  -> 权限与公司授权
  -> 钱包充值
  -> 费用预占
  -> 提交统一生成请求
  -> 模拟渠道执行
  -> 产物安全转存与短时下载
  -> 成功结算 / 失败释放
```

## 范围内

- 客户平台和中转站两个独立 FastAPI 应用。
- PostgreSQL 数据模型边界和本地测试替代。
- Redis/异步队列接口边界。
- 中转站适配器接口和一个明确标记的模拟适配器。
- 模型能力声明。
- 公司钱包不可变流水。
- 数据库约束保障的幂等任务提交与冲突检测。
- 平台管理端的公司、模型/资源授权、充值、看板与审计第一版。
- 产物 SSRF 防护、大小/MIME/哈希校验、本地跨容器转存和短时下载。
- 标准任务状态和错误码。
- Docker 化本地基础设施。
- 现有 React 工作台的 API 客户端边界。

## 暂不包含

- 真实供应商和逆向 API。
- 真实逆向账号池。
- 真实华为云 OBS 凭证。
- 在线支付。
- 公共账号注册和密码找回。
- 完整成本报表和生产告警。
- 生产域名、TLS 和正式部署。

这些项目需要真实渠道资料、云资源或业务决策，不能用模拟实现冒充完成。

## 验收

- 两个服务的测试套件通过。
- 同一幂等键不会创建两个任务。
- 不同公司不能读取彼此资源。
- 余额不足不能创建预占。
- 成功只能结算一次。
- 失败任务释放预占且余额不减少。
- 无健康渠道时返回统一可重试错误。
- 本地持久化整栈跑通预占、派发、回调、转存、下载与结算。
- 前端构建和原有 Sites 托管测试继续通过。
